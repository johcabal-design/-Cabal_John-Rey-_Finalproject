## Description
A CLI-based application designed for Filipino students to track daily expenses and allowance in PHP. This project demonstrates intermediate Python concepts including OOP, file persistence, and recursive summation.

## Features
- **Recursive Processing:** Calculates total balance using a recursive algorithm.
- **Persistent Storage:** Saves data to a CSV file.
- **Input Validation:** Error handling for invalid numeric entries.
- **Unique Categorization:** Uses Python Sets to manage spending categories.

## Installation & Setup
1. Ensure you have Python 3.x installed.
2. Download `finance_tracker.py`.
3. Run the application via terminal: `python finance_tracker.py`

# Sample CLI Usage/Screenshot
When you run the application, follow these steps to manage your finances:
1.  **Add Transaction:** Select Option `1`. Enter an amount (use negative numbers for expenses like `-20` for a Jeepney fare).
2.  **View Categories:** Select Option `2` to see all unique categories you have used.
3.  **Generate Report:** Select Option `3` to see your total balance in Philippine Peso (₱) and the performance of the recursive calculation.
4.  **Exit:** Select Option `4` to safely close the application and save your data.
